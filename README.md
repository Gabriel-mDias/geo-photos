# geo-photos

Projeto de exibição de fotos 360º, listando as mesmas em um mapa que teremos uma referência de latitude x longitude por foto.

# Requisitos técnicos

 - NodeJs na versão 18
 - Caso deseje rodar a versão mockada da API, é importante instalar o json-server

# Comandos necessários
```
nvm install 18.20
nvm use 18.20
npm i

npm i -g json-server
json-server --watch json-server/mock-db.json

ng s
```
